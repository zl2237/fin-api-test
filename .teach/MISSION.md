# Mission: pytest API Testing

## Why
学习 pytest 是为了能够为你的 fin-api-test 项目编写自动化测试用例，并构建可靠的 API 测试流程。目标是从手动测试转变为自动化验证，提高测试效率和覆盖率。

## Success looks like
- 能够独立编写 pytest 测试用例
- 熟练使用 pytest fixtures 管理测试依赖
- 能够对 HTTP API 进行完整的集成测试
- 能够设计可维护的测试数据管理方案
- 能够生成清晰的测试报告

## Constraints
- 已有 Python 基础
- 看过一些 pytest 基础语法
- 需要结合实际项目（fin-api-test）进行练习

## Out of scope
- 单元测试细节（mock/patch）
- 性能测试/压力测试
- 前端自动化测试
