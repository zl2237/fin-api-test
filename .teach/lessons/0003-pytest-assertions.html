第三课：Pytest 断言详解

核心概念： 断言是测试的核心 —— 它验证代码行为是否符合预期。pytest 的断言重写机制让错误信息非常清晰。

基础断言

断言说明示例
assert x 断言为 True assert response.ok
assert a == b 断言相等 assert code == 200
assert a != b 断言不等 assert err_code != 0
assert x in container 断言包含 assert "token" in response

数值比较

# 等于
assert response.status_code == 200

# 浮点数近似比较
assert 0.1 + 0.2 == pytest.approx(0.3)

# 大于/小于
assert amount > 0
assert balance <= limit

API 测试常用断言

def test_login_success():
    response = api.login("user", "pass")

    # 状态码断言
    assert response.status_code == 200

    # 响应体断言
    data = response.json()
    assert data["code"] == 200
    assert "token" in data
    assert isinstance(data["token"], str)

    # 字符串断言
    assert data["message"].startswith("Success")
    assert len(data["token"]) > 10

自定义断言失败信息

assert balance > 0, f"余额不足: {balance}"

assert resp.status_code == 200, \
    f"请求失败: {resp.status_code} - {resp.text}"

异常断言

import pytest

# 断言抛出指定异常
assert pytest.raises(ValueError, lambda: int("invalid"))

# 使用上下文管理器
with pytest.raises(ValueError):
    int("not a number")

你的项目中的断言

查看你的 utils/assert_util.py，应该已经封装了常用断言。

建议： 先使用 pytest 内置断言，遇到重复模式再封装工具函数。过度封装会降低可读性。
