# 交互设计指导

> 本文档是前端交互决策的依据，新增页面/改造前先对照。来源：2026-08 全局交互审计 + 主流产品（GitHub / VSCode / paperless-ngx 等）惯例归纳。

## 1. 什么操作适合进侧边栏

侧边栏每一项必须**同时满足三条**：

1. **高频**：每天 / 每次会话都会用
2. **并列**：用户会在同层几个对象间横向跳（接口 ↔ 用例 ↔ 执行）
3. **承载页面**：内容多到需要整页承载，而不是一个动作

反面信号（满足任一就不该进侧栏）：

- 它是一个**动作**而不是一个**地方**（「删除日志」是动作，「日志」是地方）
- 使用频率低（如版本管理：项目建好后可能数周不碰）
- 内容单薄，撑不起整页（如项目管理就一张表）

**本项目结论**：

- 项目管理 → 不进侧栏。低频配置 + 单表 CRUD，归宿是顶栏项目选择器旁的入口（dropdown / 抽屉 / 命令面板）
- 版本管理 → 不进侧栏。它是项目的**附属功能**，挂在项目切换器旁边最自然
- 侧栏现有项（工作台/接口/用例/执行/报告/文件中心/环境/字典/日志）均为高频并列的「地方」✓

**一句话**：侧栏 = 高频并列的「地方」；低频 / 附属 / 单表 CRUD 一律下沉到上下文入口（dropdown / 抽屉 / 弹窗）。

## 2. 什么界面用左右布局，什么用按钮跳转

**左右布局（master-detail）适用**——左侧是「选择器」，右侧是「同一实体不同实例」：

- 用户核心动线是**频繁对比 / 切换**左侧选项，每次切换右侧内容结构**相同**（表单 / 表格同构）
- 左侧项数量有限（<50）且不需要复杂筛选
- 本项目示例：分组 → 组内条目（接口 / 用例）、环境列表 → 环境详情、报告步骤导航 → 步骤详情

**按钮跳转（独立页面 / 抽屉 / 弹窗）适用**：

- **内容形态质变**：从列表进入「编排画布」——工作模式从浏览变成创作，独占整屏 + 独立路由（可分享 URL、可回退）
- **流程性任务**：长表单、多 tab、需要 Ctrl+S 和 dirty 守卫（如接口编辑、环境编辑）
- **低频完整查看**：报告详情
- **弹窗的边界**：≤3 个字段的增改（新建分组 / 字典行）、确认类操作。一旦超过 4-5 个字段或需要对比参照，就升格为独立页 / 抽屉，不做大弹窗

**反模式**：同一个实体既能在弹窗编辑又能跳页编辑，两套 UI 并行——**一个实体一条编辑路径**。

**同一实体新增与编辑必须同容器**：新增弹窗则编辑弹窗，新增抽屉则编辑抽屉，新增跳页则编辑跳页。字段数按两边**较多的一侧**定容器档位（如用户新增 5 字段 / 编辑 6 字段 → 都是抽屉）。

## 3. 什么筛选立即生效，什么要点「查询」

**立即生效**（change / 输入即触发，300ms 防抖）：

- **本地过滤**（数据已在内存）：零成本，必须即时
- **服务端查询但结果集小、查询廉价**（<300ms）：如字典搜索、文件搜索
- 单选下拉 / 日期等**低误触**控件：change 即查
- 判据：改条件的成本 < 点查询按钮的成本，且用户能看到结果即时变化形成反馈回路

**显式「查询」按钮**：

- **组合复杂查询**：≥3 个条件联动（如执行记录：时间范围 + 项目 + 状态 + 执行人）——用户要逐个填完再一起查，即时触发会疯狂发无用请求
- **昂贵查询**：跨表聚合、全文检索、慢 SQL
- **有「重置」语义**：查询 / 重置成对出现是强心智模型

**本项目统一规则**：

| 场景 | 行为 |
|---|---|
| 本地过滤（列表内搜索框） | 即时（computed） |
| 服务端单条件搜索 | 300ms 防抖 |
| ≥3 条件组合查询 | 显式查询按钮 + 重置 |

## 4. 全站状态约定（2026-08 定稿）

每个列表/详情页的三态必须按此实现，不允许页面各自发明：

| 状态 | 约定 | 组件/工具 |
|---|---|---|
| **加载中** | 首屏骨架屏 `el-skeleton`；master-detail 局部刷新用遮罩 | `skeleton-wrap` |
| **空态** | 主列表用 `EmptyState` + 引导按钮；行内配置小表（断言/字段/KV）用 `empty-text` 纯文本即可 | `components/EmptyState.vue` |
| **加载失败** | 页面级 `load()` 失败 → 内联错误块 + 重试按钮（`.app-load-error`），**不用 toast**；动作类失败（保存/删除/导入）才用 `ElMessage` | `style.css` 全局类 |
| **时间列** | 列表一律相对时间（hover title 显绝对时间），详情/弹窗可用绝对时间 | `formatRelativeTime` |
| **批量操作** | 选中行后才浮现批量操作条（已选 N｜操作｜取消），未选中不占空间 | ApiManage `bulk-bar` |
| **筛选进 URL** | 列表页筛选条件同步 `route.query`：刷新不丢、可分享链接 | Execution 参考实现 |

优先级：**错误块 > 骨架屏 > 空态 > 列表**（加载失败时不得误入空态/空壳）。

动效红线：**只留功能反馈**（上传中闪烁、主题切换、节点高亮、进度条、一次性入场）；禁止无限循环装饰动画（浮动/呼吸/涟漪/视差）。

## 5. 终态审计结论（2026-08-20 收口）

「简约、易用、独特」三原则的全站终态核对，后续新增页面照此验收：

| 维度 | 终态 |
|---|---|
| 表格密度 | 全站 `el-table` 一律 `size="small"`（22 处核对通过） |
| 四态覆盖 | 骨架屏 / EmptyState / 错误块+重试 / 动作反馈，10+ 页面全覆盖 |
| 破坏性操作 | 一律 `ElMessageBox.confirm`，高危二次确认（12 页面） |
| 回车提交 | 表单页走原生 `@submit.prevent` + `native-type="submit"`（登录/改密）；查询框 `@keyup.enter`（执行记录） |
| 兜底路由 | `/:pathMatch(.*)*` → NotFound（断链 DAG 品牌化 404），`public: true` |
| 动态标题 | `router.afterEach` 按 `meta.title` 设置 `document.title`，index.html 静态标题仅首屏兜底 |
| 品牌语言 | DAG 符号贯穿：favicon → 登录页品牌大图 → 404 断链图，三处同构 |

**已知边界（工程量级差距，非交互设计差距，按产品阶段决定是否投入）**：

1. i18n 国际化（文案中文硬编码）
2. 自定义 SVG/DAG 画布的屏幕阅读器走查与焦点管理（Element Plus 自带 aria 已覆盖标准控件）
3. 删除可恢复（软删除 + undo toast，当前为确认弹窗）
4. 大数据量虚拟滚动（列表 >1000 行、画布 >100 节点）
5. e2e 回归测试（交互规范当前靠本文档约束，缺 Playwright 防回归）

## 附：左栏点击语义（已定规范）

- **父节点**（有子分组）：单击整行 = 切换展开 / 折叠（树导航语义，与 caret 行为一致）
- **叶子节点**：单击 = 选中并在右侧展示
- 根项（「全部接口 / 用例」）：单击 = 选中
