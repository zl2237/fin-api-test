##### 一、对接地址

测试环境公网负载：http://x.x.x.x:11001
测试环境私网负载：http://x.x.x.x:11001

生产环境公网负载：http://x.x.x.x:11001
生产环境私网负载: http://x.x.x.x:11001

注：
公网适用：外部合作方、无内网互通的外部业务线
私网适用：公司内部服务、同机房内网业

##### 二、密钥使用规则

公网、私网两套负载支持共用同一套公私钥，无需分开生成两套密钥：

同一业务线使用一套公私钥，即可同时调用公网、私网两个环境接口；
鉴权逻辑统一：同一密钥在公网/私网地址验签规则完全一致；
轮换维护：密钥到期更新时，仅需替换一套即可同时适配两个环境，降低配置维护成本。
生产和测试环境禁止共用一套秘钥

##### 简要描述



批量最多100票，逐票独立受理，立即返回 batchNo。相同 bizNo 列表在5秒内重复提交会被拦截；仅限内网调用。



##### 请求方式



`POST /api/v1/customs/clearance/batchSubmit`



Content-Type: `application/json`



##### 请求字段与加密



外层仅 `requestCipher`（必填 string）。内层 JSON 按 UTF-8 编码，用线下交付的 RSA 2048 位公钥（X.509 格式）进行 `RSA/ECB/PKCS1Padding` 分段加密：每段最多 **244 字节**，每段输出 256 字节，按顺序拼接全部密文后整体 Base64。不得逐段 Base64。复用CFCA的SignatureUtils工具与分段方式；密钥以海关专用`customs.clearance.rsa-private-key`对应公钥为准，不能假定与CFCA密钥相同。


`requestTime`必须是JSON整数，不能传数字字符串；必须为正的13位毫秒时间戳。当前窗口由`customs.clearance.request-allowed-skew-millis`控制，默认±300000毫秒（5分钟）。时间窗不阻止窗口内重放，公钥加密也不验证发送者身份；内网访问控制或网关认证须由部署保障。



外层示例：
```json
{"requestCipher":"加密并整体Base64后的字符串"}
```



| 字段名                | 必选 | 类型    | 说明                                                        |
| --------------------- | ---- | ------- | ----------------------------------------------------------- |
| requestTime           | 是   | integer | 13位毫秒时间戳                                              |
| callbackUrl           | 否   | string/null | 最多1024字符；不传、null或空字符串不推送，非空需为合法HTTP(S)地址 |
| items                 | 是   | array   | 1～100项，每项独立校验                                      |
| items[].bizNo         | 是   | string  | 非空且不全为空白，最长64个Unicode码点；相同bizNo可在防重复窗口结束后再次提交      |
| items[].declarationNo | 是   | string  | 严格18位ASCII数字，保留前导零                               |



##### 请求示例（加密前）



```json
{
  "requestTime": 1793066400000,
  "callbackUrl": "http://business-service/customs/result",
  "items": [
    {
      "bizNo": "BIZ-20261027-0001",
      "declarationNo": "123456789012345678"
    },
    {
      "bizNo": "BIZ-20261027-0002",
      "declarationNo": "123"
    }
  ]
}
```



##### 返回字段



业务应答使用 `code`（integer）、`msg`（string）、`data`（object/null）。下表为 data。



| 字段名  | 必选 | 类型   | 说明                       |
| ------- | ---- | ------ | -------------------------- |
| batchNo | 是   | string | 本次受理批次号；单票也生成 |



##### 返回示例


```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "batchNo": "CUS-B-1985000000000000000"
  }
}
```
