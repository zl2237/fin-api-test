# NOTES — 术语与约定（自测相关）

- **专用自测项目**：名为 `__自测__` 的项目，接口/用例等全部写操作隔离于此，跑完整体删除。绝不写用户的真实项目（#1 物流管理系统）。
- **阻断即修**：🔴 阻断级问题（功能不可用/报错/数据损坏/测试不过）agent 立即修复并回归；🟡 非阻断（体验/风格）只记录待用户决策。
- **冒烟线**：其余模块每路由 ≥1 条 happy path，不做异常分支全覆盖。
- **brief**：对话内的决策就绪摘要（通过率/分级失败/修复状态），不落报告文件；历史不归档。
- **UI 勾选文档**：`docs/self-test/UI-CHECKLIST.md`，每轮覆盖重写；编号 `UI-<模块缩写>-<序号>`，用户勾选/批注，agent 读回。
- **一次性脚本**：`.tmp_` 前缀（gitignore 已覆盖），验证即删，不入库；可复用的逻辑必须落成 `platform/backend/tests/` 的 pytest 单测。
- **自测环境**：仅本地 dev（后端 127.0.0.1:8000、前端 vite 端口）；部署验证交 CI。
- **触发习惯**：每批功能"开发完成、交付前"，agent 主动发起，不等用户喊。
