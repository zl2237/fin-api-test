# 培训会演示脚本（20 分钟演示环节）

> 演示流：**新建 → 分发 → 提交 → 录费用 → 生成子订单**（5 个业务节点；登录/token 由环境登录配置自动完成，画布上只有业务节点）
> 原则：全程真实数据、每步有讲解要点、每幕有救场预案。彩排至少 1 遍并计时。

## 会前检查（会议开始前 30 分钟）

- [ ] 演示项目就绪：上述 5 个接口已录入（cURL 导入 + 字段示例值填全）
- [ ] 两条用例：`主流程-正常`（跑通）、`主流程-断言故意错`（演示失败定位）
- [ ] 企微群「FIN-API-TEST通知」机器人可推送（最后压轴）
- [ ] 投屏分辨率调好，浏览器放大 125%，提前登录
- [ ] 备胎：跑通用例的报告 HTML 已导出存本地（环境挂了直接放报告讲解）
- [ ] 手册第 3 节页面打开（转场衔接用）

## 分幕脚本

### 幕 0 开场钩子（1min）

- 讲：「上周【某次回归】我们手工跑了【X】小时，现在看平台跑同一条流要多久。」
- 操作：什么都不点，让屏幕停在用例列表。
- 顺带指一下浏览器标签页：「跑的时候这个图标会转，跑完变绿勾/红叉，切去干别的也不用盯。」

### 幕 1 项目与环境（3min）

| 操作 | 讲解要点 |
|---|---|
| 展示项目列表 | 「项目=业务线的文件夹，所有东西挂它下面」 |
| 环境配置页打开测试环境 | 「地址、公共头、数据库连接配一次；测试/预发各一套，执行时选」 |
| 指环境里的登录配置 | 「登录、token 续期、验证码识别都在环境层自动做——画布上只放业务节点，不用每个用例都拖个登录」 |
| 点「测试连接」 | 「上线前自查，连不上当场暴露」 |

### 幕 2 接口录入（4min）

| 操作 | 讲解要点 |
|---|---|
| 演示 cURL 导入「新建」接口 | 「浏览器 F12 复制 cURL，粘进来，地址/头/体一次全带——不用手填」 |
| 打开字段表 | 「字段示例值最重要：新建数据集时按它预填参数」 |
| 提一句字段字典 | 「费用类型这类枚举配进字典，配参数变下拉选择，不会拼错」 |

### 幕 3 画布编排与四来源参数（6min，核心）

| 操作 | 讲解要点 |
|---|---|
| 新建用例进画布，依次点入 5 个接口 | 「点击=加节点，拖=连线，连线就是先后依赖」 |
| 连成 新建→分发→提交→录费用→生成子订单 | 「这就是我们手工回归的那条主流程」 |
| 双击「新建」节点开配置抽屉 | 「Ctrl+S 保存时自动生成配套数据集，参数表已按示例值预填」 |
| 数据集里演示 4 种取值方式各一个 | 固定值=币种/类型码；**引用=「提交」「录费用」引用「新建」产生的业务单号**；函数=唯一 ID；**查库=按单号查最新数据** |
| 重点讲引用链 | 「SQL 里写 `{{新建.单号}}` 这类占位，平台自动先算依赖再执行——顺序不用你操心」 |
| 讲断言 | 「`$.code` 等于 200、`$.data.单号` 不为空；全过才算这步过」 |

### 幕 4 执行与报告（4min）

| 操作 | 讲解要点 |
|---|---|
| 回用例列表点执行，选测试环境 | 「现在计时」——同步口播这步手工要多久 |
| 报告页逐层展开 | 「每步的请求、响应、断言、提取的变量全都在；顶上总结论」 |
| 演示导出 | 「HTML 单文件，直接发给没账号的人看」 |

### 幕 5 失败定位三板斧（5min，最能打动的环节）

切换到「断言故意错」的用例报告（断言设在「录费用」步骤，如金额期望 100.00 vs 实际 99.99）：

1. **看断言**：红色行展示「期望 vs 实际」——一眼看出差在哪
2. **编辑并重放**：改请求体原地重发，「验证改成什么才能过，不污染配置」；调通挂「已重放通过」徽标
3. **同步+断点续跑**：把正确值落进数据集 → 断点续跑，「从失败那步接着跑，前面的新建/分发/提交不重复跑——**不会重复造数**」

讲红线：「重放通过≠用例修好，落数据集+续跑变绿才算数。」

### 幕 6 数据驱动与套件、定时（3min）

- 同一数据集加 2 行（正常单 / 金额为 0 的边界单）→ 执行 → 「一次出两份报告」
- 套件页：「整场回归串起来一次跑，版本发布冒烟用」
- 定时任务：「设每天 8:00，睡觉时它在跑」

### 幕 7 企微推送压轴（2min）

- 触发一次执行，切到企微群「FIN-API-TEST通知」看消息弹出：「跑完自动推群，结论一眼可见，不用挨个问」
- 收尾话术：「接下来 20 分钟，你们自己上手跑一遍——手册第 3 节，我全程答疑。」

## 救场预案

| 翻车 | 处理 |
|---|---|
| 测试环境连不上 | 切备用报告 HTML 讲解；实操环节改用 mock 说明 |
| 执行卡住 | 等待间隙讲 FAQ（Q3/Q4 最常被问） |
| 界面和手册不一致 | 当场记下，会后修手册（承诺兑现） |
